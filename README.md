# Prawda czy Wyzwanie — Android

Native Android party game project based on the supplied 84-page design and implementation document.

## Product direction

- Native Android application with a polished, premium Black & Gold visual identity.
- Multiple game modes, including Classic, Chaos, and Royal Edition.
- Configurable intensity and content categories.
- Player rotation, score tracking, round history, and duplicate avoidance.
- Royal cards / wildcard events and a target roulette mechanic.
- Custom prompt editor and session controls.
- Clear skip/pass controls and consent-first safety rules.
- Offline-first gameplay; no account or network connection required for a normal session.

## Engineering requirements

The repository is the source of truth. Changes should be committed here, tested, and documented. A feature is not considered complete until its behavior is implemented and covered by tests where practical.

## Current status

Project initialization only. The gameplay systems, UI, persistence, automated tests, and Android release build remain to be implemented and verified. No APK is claimed to exist yet.
